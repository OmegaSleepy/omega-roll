# Contributing

Thank you for your interest in contributing. This document explains how to report issues and submit changes.

Reporting issues
- Open an issue describing the problem, the browser and OS used, and steps to reproduce.

Making changes
- Fork the repo and create a branch named `doc/your-topic` or `feat/your-feature`.
- Keep changes focused and provide a short description in the PR.

Code style
- Vanilla JavaScript and simple CSS are used. Follow existing patterns for file organization.

Testing
- There are no automated tests configured; test changes manually by running a local server and verifying pages.
